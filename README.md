# CRM Team · Панель управления (MVP)

Панель управления CRM-системы в фирменном стиле CRM Team.
Логика расположения — как в Salesforce Lightning: логотип слева в шапке,
разделы — горизонтальные вкладки рядом, контент разделов встроен в одну
страницу нативно (без iframe).

## Структура

```
crm.banki.ru/
├── index.html   ← всё приложение: оболочка + все разделы
└── README.md
```

Все разделы (Панель отклонений, OneLink Builder, Мастер коммуникаций,
Список шаблонов, Дашборд) живут внутри `index.html` секциями
`<section class="view" id="sec-...">`. CSS каждого раздела изолирован
блоком `@scope (#sec-...) { ... }`, поэтому стили разделов не конфликтуют
между собой и с оболочкой.

## Возможности MVP

- **Верхняя навигация** — разделы-вкладки в шапке; активный раздел
  подсвечивается индикатором. Последний открытый раздел запоминается.
- **Мастер коммуникаций** — вкладки каналов (SMS / Push / Email / КЦ /
  Просмотр настроек) в стиле Lightning; «Список шаблонов» и «Дашборд»
  вынесены в самостоятельные разделы верхнего уровня.
- **Подсказки к полям** — значок (i) рядом с названием поля, текст
  появляется при наведении (единый формат во всех разделах).
- **Главная** — настраиваемая: кнопка «Настроить главную» включает режим,
  в котором блоки можно добавлять (чипы сверху), убирать (×) и
  перетаскивать мышью. Раскладка, задачи и история сохраняются в
  localStorage браузера.
- Блоки в каталоге: Сводка (демо-KPI), Мои задачи, Недавние инструменты,
  Быстрые ссылки, Статусы систем.

## Как добавить новый раздел

В `index.html`:

1. Добавьте секцию в `<main>`:
   `<section class="view" id="sec-myid"> …контент… </section>`
2. Стили раздела оберните в `<style>@scope (#sec-myid){ … }</style>`
   (селекторы `body`/`:root` замените на `:scope`).
3. В массив `NAV` добавьте строку:
   `{ id:"myid", label:"Название", icon:"chart", view:"sec-myid" },`

## Как добавить новый блок на главную

В `index.html` в объект `WIDGETS` добавьте запись с `title`, `eyebrow`
и функцией `render(el)` — блок автоматически появится в каталоге
«Добавить блок».

## Просмотр

Локально достаточно открыть `index.html` в браузере (для корректной
работы шрифтов и CDN-библиотек нужен интернет). Для публикации
через GitHub Pages: Settings → Pages → Source: `main` / root. Учтите,
что Pages для приватного репозитория доступен на планах GitHub Pro/Team;
альтернатива — открыть репозиторий или раздавать статику со своего
сервера/nginx.
