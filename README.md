# CRM Team · Панель управления (MVP)

Оболочка панели управления CRM-системы в фирменном стиле CRM Team:
скрывающееся левое меню с разделами, настраиваемая главная страница
с блоками и открытие инструментов внутри панели (iframe).

## Структура

```
crm.banki.ru/
├── index.html                  ← главная оболочка (открывать её)
├── pages/
│   ├── deviations-panel.html   ← Панель отклонений выручки
│   ├── onelink-builder.html    ← AppsFlyer OneLink Builder
│   └── admin-panel.html        ← Админка коммуникаций
└── README.md
```

## Возможности MVP

- **Левая колонка** — сворачивается кнопкой внизу; состояние запоминается.
- **Разделы** — при выборе открывается соответствующая html-страница.
- **Главная** — настраиваемая: кнопка «Настроить главную» включает режим,
  в котором блоки можно добавлять (чипы сверху), убирать (×) и
  перетаскивать мышью. Раскладка, задачи и история сохраняются в
  localStorage браузера.
- Блоки в каталоге: Сводка (демо-KPI), Мои задачи, Недавние инструменты,
  Быстрые ссылки, Статусы систем.

## Как добавить новый раздел

В `index.html` найдите массив `NAV` и добавьте строку:

```js
{ id:"myid", label:"Название", icon:"chart", src:"pages/my-page.html", dark:true },
```

`dark:true` — для страниц в тёмной теме (фон iframe не будет белым).
Файл страницы положите в `pages/`.

## Как добавить новый блок на главную

В `index.html` в объект `WIDGETS` добавьте запись с `title`, `eyebrow`
и функцией `render(el)` — блок автоматически появится в каталоге
«Добавить блок».

## Размещение в репозитории

```bash
git clone https://github.com/AlexRaisky/crm.banki.ru.git
cd crm.banki.ru
# скопируйте сюда содержимое архива (index.html, pages/, README.md)
git add .
git commit -m "MVP: оболочка панели управления CRM"
git push origin main
```

Если ветка называется иначе (например, `master`) — подставьте её в `push`.

## Просмотр

Локально достаточно открыть `index.html` в браузере. Для публикации
через GitHub Pages: Settings → Pages → Source: `main` / root. Учтите,
что Pages для приватного репозитория доступен на планах GitHub Pro/Team;
альтернатива — открыть репозиторий или раздавать статику со своего
сервера/nginx.
