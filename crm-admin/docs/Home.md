# Home

**crm-admin** — самописная админ-панель управления CRM-коммуникациями, заменившая low-code-админку на Appsmith.
Один артефакт Java 21 / Spring Boot 3.3 (`crm-admin.jar`) со встроенным vanilla-JS SPA поверх PostgreSQL 16, в Docker, тремя контурами (prod / preprod / test) из одного образа.
Панель ведёт шаблоны коммуникаций семи каналов (sms, push, email, cc, fa, vk, la — прод-таблицы существуют только для первых четырёх) и синхронизирует их с прод-БД, собирает цепочки коммуникаций и материализует их в конфигурацию прод-движков, а также обслуживает планирование промо, отчёты, CRM-сущности и клиентские инструменты команды.

Читать первым — [[Флоу системы]] (сквозной рассказ «как всё работает»), держать под рукой — [[Шпаргалка]].

## Фронтенд

SPA без сборки. Первые две заметки общие, остальные — по разделам.

- [[Обзор фронтенда]] — карта каталога `static/`, бутстрап, порядок скриптов, изоляция стилей `@scope`.
- [[Клиент API (api.js)]] — единственный слой доступа к REST: транспорт, маппинги DTO, `applyNavAcl`.
- [[Оболочка панели (shell)]] — App Launcher, сайдбар и flyout, обзорные страницы, тема и язык, ACL-контракт NAV.
- [[Мастер коммуникаций (формы)]] — формы каналов, автоимена, цепочка дней, карточка просмотра настроек.
- [[Сущности]] — CRM-часть панели: подразделы, списки и карточки строятся из схемы Scheme Builder.
- [[Flow Builder (цепочки)]] — канва Drawflow: типы узлов, модалка настроек, предпросмотр и материализация.
- [[Страница настроек (settings)]] — вся `/settings`: подключения к БД, прод-БД и ETL, Scheme Builder, Object Manager, db-explorer.
- [[Управление доступом и вход]] — страница входа и раздел управления пользователями и ролями в `/settings`.
- [[Отчёты и ЧЕК СМС траффик]] — встраивание книг Tableau и таблица «ЧЕК СМС траффик» на странице.
- [[Планирование промо и АБ тесты]] — два раздела одного типа: общая таблица с правкой по ячейке.
- [[Конструктор source и OneLink Builder]] — два клиентских генератора имён и ссылок, без сохранения.
- [[Панель отклонений]] — аналитика «выручка по дням» целиком в браузере (файлы называются `heatmap-*`).

## Разделы панели

Что именно делает каждый раздел на сервере:

- [[Отчёты]] — конфигурация встраивания Tableau и выгрузка «ЧЕК СМС траффик» в Excel.
- [[Планирование промо]] — общая таблица плана промо и правила совместного редактирования.
- [[АБ тесты]] — журнал А/Б тестов: период, гипотеза, шаблоны, результаты и кто тестировал.

Разделы без серверной части описаны только во фронтенд-заметках: «Сущности» (модель тянется из Scheme Builder), «Панель отклонений», «Конструктор source», «OneLink Builder».

## База данных
