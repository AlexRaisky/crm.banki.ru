## База данных

- **PostgreSQL 16** — образ `postgres:16` во всех трёх средах (`docker-compose.yml`).
- Активно используются постгрес-специфичные вещи: `jsonb` (`app.journeys.definition`, `template.d_template.channel_props`, `stop_events`), массивы (`text[]`, `bigint[]`), `interval`, `GENERATED BY DEFAULT AS IDENTITY`, `ON CONFLICT ... DO UPDATE`, `to_jsonb(t)`, GUC через `set_config('app.current_user', ...)` для прод-аудита.
- Flyway-схемы: `notice, callcenter, retention, arch, app` (+ V5/V6 создают `tracker, scheduler, template, commapi, flow`). `default-schema: app`, `create-schemas: true`.
- Профили: `docker` — миграции + сиды (`out-of-order: true`, т.к. сиды заняли версии V900+ раньше, чем появились V3+); `prod` — **Flyway выключен полностью** (таблицы уже существуют в корпоративной БД). Подробнее — [[Конфигурация]] и [[Среды и деплой]].

## Инфраструктура

- **Docker, multi-stage `Dockerfile`**: стадия сборки `maven:3.9-eclipse-temurin-21` (с прогревом кеша зависимостей `dependency:resolve` по одному `pom.xml`), рантайм `eclipse-temurin:21-jre`, запуск под непривилегированным пользователем `app`, `EXPOSE 8080`.
- **docker-compose** — три стека (prod/preprod/test) из **одного образа** `crm-admin:local`; только `app-prod` имеет секцию `build: .` — детали и процесс промоушена в [[Среды и деплой]].
- Скрипты сопровождения: `scripts/reset-test.sh`, `scripts/refresh-preprod.sh` (bash поверх `docker compose`).

## Почему так

1. **Один jar = всё приложение.** SPA внутри jar-а убирает CORS, отдельный веб-сервер и деплой фронта; аутентификация и статика живут в одном Spring Security-контуре.
2. **Никаких внешних рантайм-зависимостей.** Замена Appsmith задумывалась как self-hosted: vendored Drawflow, свой combobox вместо UI-библиотек, БД в соседнем контейнере. Единственное отступление — Google Fonts (см. выше).
3. **Flyway как единственный владелец схемы.** `ddl-auto: none` + прод-идентичные DDL в миграциях дают гарантию «test-схема == прод-схема»; на проде миграции выключены, и приложение работает с уже существующими таблицами.
4. **Lombok и records** сокращают шаблонный код: сущности — Lombok, DTO — Java records (`JourneyDtos`, `UserDtos`, `MeDto`, `EnvDto`).
